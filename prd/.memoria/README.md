# Memoria interna

Este directorio es un respaldo local cuando el entorno no dispone de memoria persistente. Su contenido no forma parte del PRD ni debe publicarse.

Las dudas activas pueden guardarse en `dudas.md` con esta estructura:

| ID | Fecha | Evidencia | Interpretación | Impacto | Pregunta | Bloquea | Estado |
| --- | --- | --- | --- | --- | --- | --- | --- |
| M-001 | AAAA-MM-DD | E-001 |  |  |  | Sí o No | Pendiente |

Cuando la autoridad final responde, se registra la conclusión en `DECISIONES.md`. La memoria puede conservar únicamente el identificador y la referencia a esa decisión.
