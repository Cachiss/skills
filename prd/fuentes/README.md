# Material original

Guarda aquí exportaciones de conversaciones, transcripciones, hojas de cálculo y documentos previos cuando exista autorización para procesarlos.

El contenido de este directorio está excluido de Git por defecto. `FUENTES.md` debe registrar la ubicación, procedencia y evidencia mínima necesaria sin duplicar información sensible.

No alteres los originales. Si hace falta normalizarlos, crea una copia de trabajo identificada como derivada.
